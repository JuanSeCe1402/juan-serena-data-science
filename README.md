# Juan Serena | Data Science & Scientific Computing

**Análisis de datos · Física computacional · Desarrollo de herramientas**

Soy Juan Manuel Serena Ceceña. Este portafolio reúne mi trabajo en análisis de datos, física computacional y desarrollo de herramientas para explorar sistemas científicos y problemas prácticos.

Este repositorio organiza proyectos recuperados del archivo personal, nuevas herramientas de preparación y propuestas por desarrollar. Cada ficha declara qué existe, qué se verificó y qué sigue pendiente. Los ejemplos sintéticos permiten explorar herramientas sin distribuir datos personales o colecciones con procedencia sin confirmar.

**Perfil:** [JuanSeCe1402](https://github.com/JuanSeCe1402)

## Empezar

```bash
python3 herramientas/verificar.py
python3 proyectos/movilidad-urbana/analizar.py
python3 proyectos/espectros-opticos/analizar.py
python3 proyectos/convergencia-manganeso/extraer.py
python3 proyectos/indicadores-stix/analizar.py
```

Esas cuatro herramientas solo necesitan la biblioteca estándar de Python y tienen casos sintéticos. Los prototipos de interfaz y aprendizaje automático tienen dependencias propias y no están cubiertos por esas comprobaciones.

## Leer el estado de cada trabajo

- **Herramienta con demo:** tiene código de entrada y un ejemplo sintético comprobado.
- **Prototipo o archivo:** conserva código recuperado, con limitaciones explícitas; no implica aplicación validada.
- **Propuesta:** describe un alcance y próximos pasos; no equivale a implementación.
