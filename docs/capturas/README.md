# Capturas de las demos

Capturas de interfaz sin alteración de contenido, tomadas el 19 de octubre de 2026 en las demos públicas de WUNSCE:

- **DARWIN:** evaluación de regresión logística, 1500 clientes ficticios, semilla 42. Los valores pertenecen a esa ejecución sintética y no acreditan rendimiento sobre clientes reales.
- **NANA:** perfil de columnas del ejemplo de seis registros ficticios. No se cargaron datos del equipo.
- **ESCULAPIO:** buzón de la sesión demo, con alias e identificadores ficticios e integraciones externas desactivadas.

Las capturas son evidencia visual de esa visita, no un monitoreo de disponibilidad. Los enlaces de las fichas abren la entrada de cada demo; no contienen identificadores de sesión ni enlaces temporales de descarga.
