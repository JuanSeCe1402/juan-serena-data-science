# Incorporación del archivo personal

Se incorporan las implementaciones NANA, DARWIN, FREY, TIKAL y ESCULAPIO, el portal WUNSCE y colecciones de métodos numéricos, fundamentos y simulación visual. Se amplía bioimpedancia con funciones recuperadas y una vía de evaluación reproducible. Las copias y versiones incompletas no se convierten en proyectos adicionales.

## Criterios

- Una versión por aplicación; ejemplos ficticios y recursos necesarios para ejecutarla.
- Sin archivos .env reales, bases locales, checkpoints anteriores, datos de pacientes, cotizaciones, respaldos, logs o entornos virtuales.
- Código de tutoriales y bibliotecas de terceros no se presenta como creación propia. El tutorial de WhatsApp encontrado no se incorpora de nuevo; se conserva su atribución como antecedente en PROCEDENCIA.
- No se añade una licencia global sobre material con autoría pendiente. Las nuevas adaptaciones y verificaciones se identifican como preparación con asistencia de Codex.
- La web específica de un cliente no se copia con sus datos y activos: la implementación pública de referencia puede documentarse como experiencia, y el portal WUNSCE aporta un caso de sitio web en este repositorio.

El manifiesto identifica nombres de fuentes y hashes, sin publicar rutas privadas del equipo. Las modificaciones de preparación se explican en cada ficha y en VALIDACION.
