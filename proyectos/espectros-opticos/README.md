# Procesamiento de espectros ópticos

Herramienta de lectura de CSV instrumentales con metadatos y pares numéricos. Resume cada señal y ofrece un caso de prueba sintético.

**Área:** Señales y datos científicos · **Estado:** Herramienta CLI con demo sintética

## Uso

```bash
python analizar.py
```

## Alcance y limitaciones

Los nueve CSV instrumentales originales no se publican por procedencia pendiente. El máximo detectado es un máximo global, no una identificación física validada de picos.

## Siguiente desarrollo

Añadir calibración, tratamiento de ruido, unidades verificadas y comparación de réplicas.
