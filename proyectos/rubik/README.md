# Cubo de Rubik: algoritmos e interfaz

Versiones de un explorador del cubo con Tkinter, biblioteca kociemba y experimentos de renderizado OpenGL.

**Área:** Algoritmos y gráficos 3D · **Estado:** Prototipos en revisión

## Material recuperado

- `archivo/interfaz.py`
- `archivo/render_3d.py`

Los archivos de `archivo/` conservan prototipos del archivo personal. Su presencia no acredita ejecución, resultados ni autoría exclusiva. Las adaptaciones nuevas se identifican en la documentación.

## Entorno

Python 3.10 o posterior. Crea un entorno virtual e instala `requirements.txt` desde esta carpeta. Las dependencias históricas no se han fijado a versiones comprobadas. Tkinter puede requerir un paquete del sistema.

## Alcance y limitaciones

La corrección de las permutaciones y el vínculo entre renderizado y estado no están verificados.

## Siguiente desarrollo

Probar movimiento-inverso, cuatro giros y conservación de piezas antes de medir soluciones.
