# Balance exploratorio de almacenamiento de hidrógeno

Prototipo de balance de producción, consumo, presión, pérdidas y energía en un tanque idealizado. El perfil de demanda es sintético: se corrigió el comentario que lo describía como datos reales y se fijó la semilla del ruido para repetibilidad.

**Estado:** archivo científico; sintaxis revisada. No se ejecutó ni se verificó balance energético, unidades, ecuación de estado o seguridad de equipos. Sus límites de presión son supuestos del programa, no especificaciones de ingeniería. No usar para controlar un sistema físico.

Fuente: script del archivo personal; procedencia académica específica pendiente de documentar. Puede generar gráficas y archivos al ejecutarse. Revisar primero [archivo/simulacion.py](archivo/simulacion.py). Requiere NumPy, pandas y Matplotlib.
