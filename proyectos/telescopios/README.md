# Simuladores de telescopios

Prototipos de visualización de espejos y rayos para configuraciones Newton, Gregory y Cassegrain.

**Área:** Óptica y simulación · **Estado:** Prototipos con entradas pendientes

## Material recuperado

- `archivo/cassegrain/figuras.py`
- `archivo/cassegrain/cassegrain.py`
- `archivo/newton/figuras.py`
- `archivo/newton/newton.py`
- `archivo/newton/prueba.py`
- `archivo/gregory/figuras.py`
- `archivo/gregory/gregory.py`

Los archivos de `archivo/` conservan prototipos del archivo personal. Su presencia no acredita ejecución, resultados ni autoría exclusiva. Las adaptaciones nuevas se identifican en la documentación.

## Entorno

Python 3.10 o posterior. Crea un entorno virtual e instala `requirements.txt` desde esta carpeta. Las dependencias históricas no se han fijado a versiones comprobadas. Tkinter puede requerir un paquete del sistema.

## Alcance y limitaciones

Faltan archivos de entrada DATOS_* y otros recursos referenciados. Los scripts no se presentan como simuladores validados.

Documentar la geometría y generar entradas de ejemplo verificadas para cada configuración.
