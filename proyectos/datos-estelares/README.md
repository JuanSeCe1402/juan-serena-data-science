# Modelos estelares y visualización con SQLite

Archivo de scripts para estructura estelar, importación de datos y exploración de variables físicas. Los modelos derivados de StatStar se conservan como material académico con atribución pendiente de precisar.

**Área:** Astrofísica y bases de datos · **Estado:** Archivo académico en revisión

## Material recuperado

- `archivo/modelo_estelar.py`
- `archivo/importar_datos.py`
- `archivo/visualizador.py`

Los archivos de `archivo/` conservan prototipos del archivo personal. Su presencia no acredita ejecución, resultados ni autoría exclusiva. Las adaptaciones nuevas se identifican en la documentación.

## Entorno

Python 3.10 o posterior. Crea un entorno virtual e instala `requirements.txt` desde esta carpeta. Las dependencias históricas no se han fijado a versiones comprobadas. Tkinter puede requerir un paquete del sistema.

## Alcance y limitaciones

La base SQLite y salidas originales no se incluyen. Los scripts conservan nombres de archivos históricos y pueden necesitar adaptación. Debe documentarse el origen de StatStar y comprobar los modelos antes de redistribuirlos bajo otra licencia.
