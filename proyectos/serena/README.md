# Serena: arquitectura de datos biomédicos

Propuesta de separación entre almacenamiento, procesamiento de laboratorio, imágenes y modelos. El primer alcance recomendado es una base sintética de experimentos.

**Área:** Ingeniería de datos y biofísica · **Estado:** Propuesta conceptual

## Alcance y limitaciones

No contiene pacientes, expedientes, imágenes médicas ni bases privadas. No implementa diagnóstico o decisiones de tratamiento.

## Siguiente desarrollo

Definir un esquema mínimo, fabricar datos sintéticos y desarrollar consultas reproducibles.
