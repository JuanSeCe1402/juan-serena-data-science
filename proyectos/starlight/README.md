# Starlight: propuesta de observación y datos meteorológicos

Diseño de un flujo de adquisición de nubosidad, almacenamiento SQL, visualización y predicción para planificación de observación.

**Área:** Datos, astronomía y divulgación · **Estado:** Propuesta conceptual

## Alcance y limitaciones

La presentación recuperada acredita una propuesta, no un sistema desplegado. No se incluyen credenciales de API ni bases privadas.

## Siguiente desarrollo

Implementar un recolector con fuente autorizada, persistencia y una evaluación retrospectiva de la predicción.
